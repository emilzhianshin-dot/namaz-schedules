## Формат данных

В manifest.json поле schedules содержит доступные наборы расписаний: год, версию, относительный путь к файлу, города, период, размер в байтах и SHA-256. Поле completeYear показывает, охватывает ли набор полный год.

В 2026.json поле cities содержит города с устойчивыми идентификаторами safadzhay и moscow, часовым поясом Europe/Moscow и массивом days. Каждая запись содержит date (ГГГГ-ММ-ДД), fajr, zuhr, asr, maghrib, isha (ЧЧ:ММ). Все времена местные. Восход и тахаджуд в эти исходные таблицы не входят и не добавлялись.

## Как планируется обновление приложения

Приложение будет проверять список доступных расписаний, скачивать файл целиком, проверять формат, период, города и контрольную сумму и сохранять данные на телефоне для работы без интернета. При ошибке загрузки сохранённые данные должны оставаться доступными.

Подключение к Android-приложению ещё не реализовано. Публикация файлов не изменяет установленное приложение.

## Добавление нового года

1. Подготовить и проверить расписание для нужных городов и года.
2. Сохранить его в том же формате JSON, указав точный период покрытия.
3. Добавить запись в manifest.json с новой версией, размером и SHA-256 файла.
4. Опубликовать файлы вместе и проверить доступность через GitHub Pages.

При исправлении существующего набора увеличивать его version и обновлять контрольную сумму и размер. Приложение должно использовать данные только в пределах объявленного периода.
