# Намаз Вакытлары — расписания

Хранилище расписаний намазов для Сафаджая и Москвы.

[Список доступных расписаний (manifest.json)](./manifest.json)

Сейчас список пуст: проверенные расписания ещё не опубликованы. Подключение к Android-приложению будет добавлено отдельно.

## Как планируется обновление

Приложение будет проверять список доступных расписаний, скачивать опубликованные данные целиком и сохранять их на телефоне для работы без интернета. При ошибке загрузки сохранённые данные должны оставаться доступными.

## Добавление нового года

1. Подготовить и проверить расписание для нужных городов и года.
2. Сохранить его в согласованном с приложением формате JSON.
3. Опубликовать файл и добавить запись о нём в manifest.json.
4. Проверить доступность файла через GitHub Pages.

Версия формата списка: schemaVersion = 1. Поле schedules содержит только опубликованные и проверенные наборы данных. До согласования формата с тестовой версией приложения список остаётся пустым.
